Digital Twin Logistics

QR-Based Digital Twin Logistics 시스템

기간

Apr 2025 – Oct 2025

유형

팀 프로젝트 · 한이음 공모전

기술 스택

Python, C#, C++, ROS 2, MoveIt 2, YOLO, Unity

시스템

QR 정보를 queue에 저장하고 ultrasonic sensor로 conveyor 도착을 감지한 뒤, robot arm이 목적지별 pick-and-place를 수행하도록 구성했습니다. Unity는 전체 system state를 visualizing했습니다.

Engineering Challenge

핵심 과제는 perception, conveyor control, manipulation, simulation 사이의 communication delay와 실행 순서를 맞추는 것이었습니다. UDP 기반 state exchange와 명시적인 control sequence로 실제 시스템과 digital twin을 동기화했습니다.

Robotic Manipulation

RGB-D Robot Arm Pick-and-Place

기간

Jul 2025 – Feb 2026

유형

개인 프로젝트 · IRC Lab 세미나

기술 스택

ROS 2, Python, RealSense D435, YOLOv11 Segmentation, tf2, MoveIt 2

Pipeline

RGB-D input → segmentation mask → depth 기반 3D estimation → camera-to-robot transform → MoveIt 2 target pose → pick-and-place

Engineering Challenge

초기 AprilTag 기반 estimation에서 markerless segmentation 방식으로 확장했습니다. Depth noise와 coordinate frame 검증은 mask 기반 sampling, tf2, RViz2를 이용해 처리했습니다.

Mobile Robotics

Autonomous Following & Towing Robot

기간

Sep 2025 – Jun 2026

역할

시스템 integration

기술 스택

ROS 2, RPLiDAR S2, ros2_control, SLAM, Nav2, PyQt5, RS485

시스템

robot은 worker following, path recording, 반복 autonomous navigation, cart towing, 상태 monitoring, GUI 기반 fine manual control을 지원합니다.

Engineering Challenge

기존 기능 코드를 hardware, tracking, path, navigation, GUI, mode-management layer로 재구성했습니다. SIGINT → SIGTERM → SIGKILL 단계의 shutdown strategy로 mode 전환 시 process conflict를 줄였습니다.
