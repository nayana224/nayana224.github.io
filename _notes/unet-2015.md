## Abstract
- **문제**: 딥러닝은 보통 많은 labeled data가 필요한데, biomedical image 분야는 annotation 확보가 어렵다.
- **핵심 아이디어**
  - `contracting path`에서 `context`를 얻고, `expanding path`에서 정확한 `localiaztion`을 수행한다.
- **학습 전략**: 적은 데이터를 보완하기 위해 강한 data augmentation을 적극적으로 사용한다.
- **주장**: 매우 적은 이미지로도 end-to-end 학습 가능하다.
- **근거**: 기존 sliding-window CNN보다 더 좋은 segmentation 성능을 보였고, 다른 biomedical segmentation challenge에서도 우수한 결과를 냈다.

## 1. Introduction
기존 sliding-window segmentation은 느리고, 큰 patch를 쓰면 context는 좋지만 localization이 나빠지고, 작은 patch를 쓰면 localization은 좋지만 context가 부족하다.
그래서 U-Net은 `contracting path`에서 `context`를 얻고, `expanding path`에서 `resolution`을 복원하면서, `contracting path의 high-resolution featrue를 같이 사용`해 `precise localization`을 수행한다.

## Figure 1 

<p class="figure-note"><strong>Visual reference:</strong> U-shaped encoder-decoder와 skip connection은 위 <b>Figure 1</b>에 단순화해 redraw했다. 원 논문의 상세 channel/resolution 표기는 <a href="https://arxiv.org/abs/1505.04597">U-Net paper Figure 1</a>에서 확인할 수 있다.</p>

- Contracting path (왼쪽 부분)
  resolution 감소, channel 증가, context / semantic feature 획득
- Bottleneck (맨 아래 부분)
  가장 압축된 feature representation
- Expanding path (오른쪽 부분)
  upsampling, resolution 복원
- Skip connection
  encoder의 high-resolution feature를 decoder에 전달, localization 정보 보완
- 1x1 Conv
  각 pixel을 최종 class로 mapping

## 2. Network Architecture
- Encoder: `Conv → Conv → Pool`
- Downsampling할수록 channel 증가
- Decoder: `Up-conv → concat → Conv → Conv`
- Skip connection으로 encoder의 spatial detail 전달
- 마지막 `1x1 Conv`로 pixel-wise class prediction
- 원본 논문은 valid convolution이라 crop 필요

## 3. Training
```python
Input image
↓
U-Net
↓
pixel별 feature / class score
↓
pixel-wise softmax
↓
pixel별 class probability
↓
GT segmentation map과 비교
↓
weighted cross entropy
↓
backpropagation
```
U-net은 classification처럼 이미지 하나에 label 하나를 주는 게 아니라, `각 pixel마다 class probability를 예측하고, 각 pixel의 GT label과 비교해서 loss를 계산한다.`

1. pixel-wise softmax
  - 각 pixel 위치마다 class 확률을 만든다.
2. weighted cross entropy
  - 모든 pixel을 동일하게 취급하지 않고, 중요한 pixel에는 더 큰 weight를 준다.
3. touching cell border 강조
  - 두 cell 사이의 좁은 boundary를 더 잘 학습하도록 loss weight를 키운다.

## 3.1 Data Augmentation
- labeled biomedical data가 적어서 augmentation이 중요하다.
- 일반적인 shift/rotation뿐 아니라 **elastic deformation**을 적극적으로 사용한다.
- 목적은 작은 데이터셋에서도 deformation에 강건한 segmentation model을 학습하는 것이다.

cf) `elastic deformation`: 이미지를 고무판처럼 자연스럽게 휘고 찌그러뜨리는 data augmentation
```python
이미지 위에 coarse 3×3 grid를 둠
↓
각 grid point를 랜덤하게 이동
↓
그 사이의 이동량을 bicubic interpolation으로 부드럽게 연결
↓
전체 이미지가 고무처럼 변형됨
```

## Conclusion 
- U-Net은 여러 biomedical segmentation task에서 성능이 좋았다.
- elastic deformation 기반 augmentation 덕분에 적은 annotation으로도 학습 가능했다. 
- 구조가 특정 biomedical dataset 하나에만 국한되지 않고, 다른 segmentation task에도 확장 가능하다고 보았다.

## 참고 개념
### 1) 기존의 sliding-window CNN이란?
이미지를 한 번에 segmentation하는 게 아니라, 각 pixel 주변의 작은 patch를 잘라서 그 중심 pixel의 class를 예측하는 방식

### 2) IoU (Intersection over Union, 교집합/합집합)
정의: prediction mask와 GT mask가 얼마나 겹치는지를, 교집합을 합집합으로 나누어 측정하는 segmentation metric이다.
GT가 실제 object 영역이고 모델 prediction 영역이 있다고 하자. 
이때 두 mask를 겹치면:
- 둘 다 object라고 한 영역 = `Intersection` 
- 둘 중 하나라도 object라고 한 영역 = `Union`
\\(IoU=\frac{\lvert Prediction\cap GroundTruth\rvert}{\lvert Prediction\cup GroundTruth\rvert}\\)

Binary segmentation에서:
- TP: object인데 object라고 예측
- FP: background인데 object라고 예측
- FN: object인데 background라고 예측
- TN: background인데 background라고 예측
\\(IoU=\frac{TP}{TP+FP+FN}\\)

### 3) Warping error / Rand error / Pixel error 개념
- **Pixel error**: 가장 단순하게, pixel 단위로 GT와 prediction이 얼마나 다른지 본다. 즉 잘못 분류된 pixel 비율에 가깝다.
- **Rand error**: segmentation이 객체/영역을 얼마나 올바르게 묶고 분리했는지를 본다. 두 pixel 쌍을 잡았을 때, GT에서 같은 객체인지 다른 객체인지와 prediction의 관계가 얼마나 일치하는지를 평가한다.
- **Warping error**: segmentation의 위상(topology)이 얼마나 잘 맞는지를 본다. 예를 들어 하나여야 할 구조가 끊겼다거나, 분리되어야 할 두 구조가 붙어버린 오류에 민감하다.
```python
Pixel error
→ 픽셀 하나하나가 맞았나?

Rand error
→ 픽셀들이 올바른 객체/영역으로 묶였나?

Warping error
→ 구조가 끊기거나 붙는 등 topology가 틀리지 않았나?
```
→ 수치가 낮을수록 좋다.
