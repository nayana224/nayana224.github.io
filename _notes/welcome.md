이 페이지는 앞으로 제가 공부하고 구현한 내용을 직접 기록하기 위한 공간입니다.

## 기록할 내용

- Deep Learning 기초와 논문 읽기
- ROS 2 / Robotics 구현
- VLM / VLA / Robot Learning
- 실험 과정과 debugging 기록

새 글은 `_notes/` 폴더에 Markdown 파일을 추가하는 방식으로 작성합니다.

## 예시

```markdown
---
title: "글 제목"
date: 2026-09-19
category: Deep Learning
summary: "목록에 표시할 짧은 설명"
---

여기부터 본문을 Markdown으로 작성합니다.
```
