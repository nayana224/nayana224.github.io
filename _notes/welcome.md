이 페이지는 공부하며 이해한 내용을 공개 가능한 형태로 다시 정리하기 위한 공간입니다.

## 기록할 내용

- Deep Learning / AI 기초 개념과 이론
- 논문 읽기와 핵심 메커니즘 정리
- ROS 2 / Robotics의 일반적인 개념과 구조
- 공개 가능한 구현 및 재현 기록
- Agent / Multimodal / Robot Learning 개념 정리

연구실 내부 작업, 미공개 연구 내용, 실험 설정·결과, private repository나 협업자 정보처럼 민감할 수 있는 내용은 이곳에 옮기지 않습니다.

Notion은 공부 과정의 working note로 사용하고, 이 사이트에는 내용을 그대로 복사하지 않고 공개 가능한 개념만 다시 검토해 정리합니다.

새 글은 `_notes/` 폴더에 Markdown 파일을 추가하는 방식으로 작성합니다.
