About me

저는 ROS 2 기반 robotic system을 만들고, sensor와 hardware interface부터 perception, planning, control, GUI까지 실제 robot이 동작하기 위한 전체 흐름을 연결해왔습니다.

특히 RGB-D perception과 Robotic Manipulation에 관심이 많고, 최근에는 Robot Learning, VLM, VLA, LLM Agent가 기존 robotics stack과 어떻게 결합되는지를 공부하고 있습니다.

이 페이지에는 제가 직접 만든 프로젝트, 현재 공부 중인 주제, 그리고 AI·Robotics 관련 최신 내용을 짧게 정리한 briefing을 모아두고 있습니다.

Core Responsibilities

  • System Integration: ROS 2, sensor, motor interface, navigation, manipulation, GUI를 하나의 maintainable system으로 통합합니다.
  • Perception to Action: RGB-D, segmentation, 3D estimation, coordinate transform, MoveIt 2를 실제 robot action으로 연결합니다.
  • Robot Learning: Imitation Learning, VLA, policy learning을 기존 robotics pipeline과 연결하는 방법을 공부합니다.
  • Agent Planning: VLM 기반 scene understanding과 LLM high-level planner를 deterministic robot primitive와 연결하는 구조에 관심이 있습니다.
