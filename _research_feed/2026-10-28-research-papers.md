휴머노이드가 걷고, 물건을 집고, 쪼그려 앉거나 발로 문을 닫는 작업을 학습하려면 **실물 로봇으로 모든 장면을 반복 시연해야 할까?** 2026년 10월 26일 공개된 *Zero-HLM: Generalizable Humanoid Loco-Manipulation without Real Robot Data*는 시뮬레이션에서 출발한 소수의 시연을 수천 개의 물리적으로 실행 가능한 궤적으로 확장한 뒤, 실물 Unitree G1에 직접 배포하는 방법을 제시한다.

이 논문이 겨냥하는 병목은 합성 영상의 외형만이 아니다. 카메라 영상이 실제와 비슷해도 **보행·균형 제어기가 계획된 발·몸통·손 위치를 정확히 따라가지 못하면** 파지 위치가 틀어지고 작업은 실패한다. 따라서 시각적으로 그럴듯한 장면과 실행 가능한 whole-body trajectory를 동시에 만들어야 한다.

## 스마트폰 장면에서 물리 시뮬레이터까지

첫 단계는 smartphone 영상에서 **Gaussian Splatting**으로 공간의 외형을 복원하는 것이다. 여기에 Blender MCP를 사용하는 multimodal agent가 물체·관절·충돌 형상·마찰·질량을 갖춘 편집 가능한 물리 장면을 구성한다. Gaussian 렌더와 물리 mesh 렌더를 같은 카메라 시점에서 비교해 정렬하고, 실제 학습 영상은 두 렌더를 합성해 만든다.

이는 Gaussian 표현 자체로 충돌을 계산한다는 뜻이 아니다. **외형은 Gaussian, 접촉과 동역학은 물리 mesh**가 담당한다. 연구진의 해당 장면 재구성에는 7시간 13분이 들었고, LiDAR 기준 대칭 Chamfer distance는 Gaussian 가이드를 사용하지 않은 구성의 11.689 cm에서 5.517 cm로 줄었다. 이 값은 논문에 사용된 재구성 장면의 기하 정확도이지 모든 물체의 파지 오차는 아니다.

## 45개 시연에서 4,800개 성공 궤적으로

연구진은 세 작업에서 각각 15개, 총 **45개의 시뮬레이션 teleoperation 원본 시연**을 준비했다. 새로운 물체·시작 위치를 샘플링하면 보행은 A* 경로와 SONIC whole-body reference로 다시 만들고, 조작 구간의 손 목표는 물체의 SE(3) 변환에 맞춰 옮긴다.

중요한 단계는 **motion–environment co-adaptation**이다. 생성한 참조 궤적을 실제 배포에 사용할 SONIC 제어기로 시뮬레이션 실행하고, 손·몸통의 추종 오차 때문에 파지가 빗나가면 객체의 평면 위치·방향 또는 손목의 높이 참조를 수정한 뒤 다시 실행한다. 충돌·낙상·작업 실패 기준을 통과한 궤적만 학습 데이터로 채택한다. 이는 실제 로봇이 물체를 옮겨서 실패를 숨기는 기능이 아니라 **시뮬레이션 데이터 생성 단계의 수정 절차**다.

그 결과 세 작업에서 총 **4,800개의 성공 시뮬레이션 시연**을 생성했다. 다만 모든 생성 시도가 성공한 것은 아니다. 작업별 생성 성공률은 **33%, 34%, 25%**였으며, 실패 시도와 재실행 비용이 존재한다. 성공 시연 50개를 모으는 시간은 실물 teleoperation 대비 평균 1.8배 빨랐다고 보고하지만, 이 비교의 실물 수집 시간에는 setup 비용이 포함되지 않는다.

## 실제 Unitree G1에서 확인한 범위

정책은 RGB·로봇 상태를 입력받아 **64차원 SONIC motion latent와 양손 명령 2개**를 예측한다. 동결된 SONIC decoder가 몸통 관절 목표를 만들며, action chunk는 RTC를 이용해 50 Hz 실행 경로와 연결된다. 실물 로봇은 29-DoF Unitree G1이고, 손은 각각 단일 개폐 명령으로 제어된다. 따라서 이 결과는 다자유도 손가락 조작의 검증과는 구분해야 한다.

연구진은 GR00T N1.7을 동일한 기본 장면(Base)에서 평가했다. 세 작업은 **바나나 집어 바구니에 놓기**, **쪼그려 앉아 모자를 집고 운반해 놓기**, **양손으로 바구니를 들고 발로 장애 문을 닫은 뒤 놓기**다. 작업당 실물 평가 20회이며, 전체 작업을 끝낸 비율을 비교한다.

| 학습 데이터 | 세 작업 평균 전체 성공률 |
| --- | ---: |
| 실물 시연 100개/작업 | 46.7% |
| 시뮬레이션 100개/작업 | 43.3% |
| 시뮬레이션 800개/작업 | **66.7%** |

즉, **66.7% 대 46.7%는 서로 같은 시연 수를 비교한 결과가 아니다.** 더 많은 시뮬레이션 데이터를 만들 수 있다는 이점까지 포함한 비교다. 별도의 다섯 가지 시작 위치·집기/놓기 위치·물체 목표 변경 평가(총 100회)에서는 실물 데이터 기준선 **23%**, 확장 시뮬레이션 데이터 정책 **69%**를 보고했다. 이 결과 역시 연구진이 설정한 장면 변형 범위 안에서만 성립한다.

## 재현할 때 가장 먼저 검증할 가정

실무적으로 중요한 점은 **시각 정합과 실행 정합을 별도 실패 원인으로 기록**하는 것이다. (1) Gaussian과 충돌 mesh가 같은 좌표계·척도에 있는가, (2) SE(3) retargeting 후 IK와 whole-body controller가 접촉 목표를 재현하는가, (3) 실제 카메라 영상과 합성 영상의 차이가 정책 판단을 바꾸는가를 순서대로 측정할 수 있다.

실제로 논문은 같은 Task A에서 실물 데이터 정책과 시뮬레이션 데이터 정책의 **시뮬레이션/실물 성공률 순위가 뒤집히는 사례**를 보고한다. 따라서 simulation benchmark가 실제 작업의 난도를 대략 반영할 수 있어도, **정책 순위를 정확히 예측한다고 볼 수 없다**. 합성 데이터와 실물 데이터를 단순 혼합하는 것도 항상 더 낫지 않았다. 영상 도메인 차이가 원인일 수 있다는 저자 분석은 별도 검증이 필요하다.

이 연구는 **특정 G1 플랫폼, 세 작업, 알려진 장면의 제한된 변형**에서 평가됐다. 'without Real Robot Data'는 **정책 학습에 실물 시연이 필요하지 않았다는 뜻**이지, 실물 카메라 보정·로봇 설정·현장 평가가 불필요하다는 뜻이 아니다. 또한 합성 시연 생성과 시뮬레이션 검증에는 GPU·장면 제작·컨트롤러 설정 비용이 든다.
