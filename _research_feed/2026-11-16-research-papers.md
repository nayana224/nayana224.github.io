[TouchTwin: Scaling Human Touch Data via Real-to-Sim-to-Real](http://arxiv.org/abs/2611.17619v1)은 정교한 조작(dexterous manipulation)을 위해 인간 시연 데이터를 시뮬레이션으로 확장할 때 발생하는 '힘의 간극(force gap)' 문제를 해결한다. 기존 비전 기반 Real-to-Sim-to-Real 파이프라인은 손의 궤적과 표면 정지 위치만 복원할 뿐, 어떤 손가락이 언제 얼마나 강하게 물체를 누르는지 알지 못해 실제보다 약하거나 과도한 힘으로 파지하는 한계가 있었다. 이 논문은 머리·손목 RGB-D 카메라와 880-taxel 촉각 장갑으로 수집한 실제 인간 촉각 데이터를 MuJoCo 물리 시뮬레이션에 직접 접목해 이 문제를 해결한다.

## 핵심 방법론

`[RGB-D 영상 및 880-taxel 촉각 장갑 데이터] -> [코딩 에이전트 기반 물체 물리 모델링 & 촉각 기반 MuJoCo 재현] -> [힘·접촉 라벨이 포함된 증강 시연 데이터 및 파지 정책]`

- **다중 모달 인간 시연 수집**: 머리 및 손목에 장착된 RGB-D 카메라와 880개의 촉각 센서(taxel)가 내장된 장갑을 사용해 TouchScale 데이터셋의 파지 상호작용을 기록한다.
- **코딩 에이전트 기반 물체 모델링**: 코딩 에이전트(Coding agents)가 시연에 등장하는 물체들을 물리 테스트를 거친 프로그램 형태로 작성해 MuJoCo 시뮬레이션 환경에 구축한다.
- **촉각 기반 물리 재현(Touch-grounded Replay)**: 피험자별 맞춤형 촉각 핸드 모델이 기록된 촉각 데이터를 기준으로 각 손가락의 접촉 시점과 닫히는 힘(closing force)을 설정해 상호작용을 정확히 재현한다.
- **섭동 데이터 증강 및 렌더링**: 재현된 시뮬레이션을 시드(seed)로 삼아 다양한 시점과 새로운 장면으로 변형된 시연 데이터를 생성하고, 시뮬레이션된 접촉 및 힘 라벨과 함께 사실적인 비디오로 렌더링한다.

## 실험 및 검증

시뮬레이션 환경에서 기존 포즈 모방 정책 및 비전 기반 물리 재현 정책과 비교한 결과, TouchTwin의 촉각 기반 재현으로 학습한 정책이 실제 인간의 파지 힘에 가장 근접한 성능을 보였다.

| 평가 지표 / 정책 | 포즈 모방 정책 (Pose Imitation) | 비전 기반 재현 (Vision-based Replay) | TouchTwin (촉각 기반 재현) |
| :--- | :---: | :---: | :---: |
| 기록된 힘 대비 파지 힘 비율 | 0.31x | 1.55x | **0.99x** |
| 홀드아웃(Held-out) 시연 성공률 | - | - | **20 / 20** |
| 미지 섭동(Unseen Perturbations) 성공률 | - | - | **35 / 36** |
| 접촉 예측기 실제 접촉 프레임 누락률 | - | 32% | **13%** |

**한계점(Caveat)**: 초록에 제시된 정량적 평가(파지 힘 비율, 성공률, 접촉 예측기 누락률 등)는 주로 시뮬레이션 환경과 TouchScale 기록 데이터를 기반으로 검증되었으며, 실제 로봇 하드웨어 플랫폼에서의 직접적인 폐루프(closed-loop) 제어 성능은 초록에 명시되어 있지 않다.

## 엔지니어링 관점의 시사점

- **비전 전용 텔레오퍼레이션 및 시뮬레이션의 한계 보완**: 손가락 관절 위치(pose)만 추적해 학습하면 물체 표면 접촉 이후의 압력 조절에 실패하기 쉽다. 정교한 파지나 힘 제어가 필요한 로봇 파이프라인에서는 촉각 센서 데이터를 시뮬레이션 보상이나 제어 목표(closing force)로 직접 매핑하는 설계가 필수적이다.
- **코딩 에이전트를 활용한 Real-to-Sim 자동화**: 복잡한 비정형 물체의 물리 파라미터와 메시를 수작업으로 구축하는 대신, 코딩 에이전트가 물리 테스트를 거쳐 물체 모델을 코드로 생성하게 함으로써 Real-to-Sim 파이프라인의 확장성을 크게 높일 수 있다.
- **라벨링 비용 없는 촉각·힘 데이터 증강**: 실제 환경에서 다양한 시점과 조명 조건마다 촉각 라벨을 새로 수집하는 대신, 한 번 정확히 재현된 촉각 시뮬레이션을 시드로 삼아 시각적·물리적 섭동을 가하고 렌더링하는 방식은 데이터 효율성을 극대화하는 실용적 전략이다.
